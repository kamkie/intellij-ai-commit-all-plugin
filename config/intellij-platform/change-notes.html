v0.1.0: first stable release.

  • Add AI, Commit, and Push controls to the non-modal Commit tool window, using JetBrains AI Assistant to generate commit messages for Git changes.
  • Support changelists, multiple Git roots, and Git staging-area workflows while preserving the IDE's commit checks and confirmed file selection.
  • Push normally without the Push Commits dialog when the branch and upstream state are safe, including outgoing commits; use the IDE dialog when commit-and-push needs user input.
  • Offer configurable AI timeout, completion checks, message clearing, and optional IDE commit and push shortcut takeover.
  • Require JetBrains AI Assistant and IntelliJ Platform 2026.2/build 262, with IntelliJ IDEA, PyCharm, and WebStorm verifier and automated UI coverage.
